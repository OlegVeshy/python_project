# CalendarBot

Telegram-бот для ведения личного календаря через сообщения на естественном
языке. Пользователь пишет событие обычной фразой, бот разбирает текст через
OpenAI, сохраняет событие в локальную SQLite-базу и позволяет посмотреть или
удалить сохранённые события.

Проект выполняется индивидуально.

## Возможности первой итерации

- запуск реального Telegram-бота на `aiogram`;
- разбор текстовых сообщений через OpenAI;
- структурированный ответ LLM в формате JSON;
- модель события на `dataclass`;
- хранение событий в SQLite;
- привязка событий к Telegram `user_id`;
- просмотр текущих событий командой `/list`;
- удаление события командой `/delete`;
- отмена удаления через `/cancel`, `cancel` или `отмена`;
- автоматическая очистка прошедших событий;
- обработка части ошибок и некорректных ответов LLM.

## Что добавлено во второй итерации

- постоянная Telegram-клавиатура с основными действиями;
- более читаемые карточки событий в списке и после сохранения;
- предпросмотр события, распознанного через OpenAI, перед записью в базу;
- inline-кнопки `Сохранить` и `Отмена` для черновика события;
- удаление событий через inline-кнопки без ручного ввода номера;
- асинхронный OpenAI-клиент, чтобы бот не блокировал обработку сообщений во время разбора.

## Стек

- `aiogram` — работа с Telegram Bot API;
- `openai` — разбор сообщений через LLM;
- `sqlite3` — локальное хранение событий;
- `python-dotenv` — загрузка переменных окружения из `.env`;
- `dataclasses` — модели конфигурации и событий.

## Структура проекта

```text
calendar_bot/
  config.py             # загрузка настроек
  events.py             # модели ParsedEvent и Event
  exceptions.py         # пользовательские исключения
  llm_parser.py         # разбор текста через OpenAI
  main.py               # точка входа
  sql_storage.py        # работа с SQLite
  telegram_handlers.py  # обработчики Telegram-сообщений
  telegram_utils.py     # вспомогательные инструменты для Telegram-логики
```

## Настройка

### 1. Создать и активировать виртуальное окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Создать Telegram-бота

1. Открыть Telegram.
2. Найти `@BotFather`.
3. Выполнить команду `/newbot`.
4. Скопировать выданный токен.

### 4. Создать `.env`

Скопировать пример:

```bash
cp .env.example .env
```

Заполнить значения:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
OPENAI_API_KEY=your_openai_api_key
DATABASE_PATH=calendar_bot/database.sqlite3
```

## Запуск

```bash
source .venv/bin/activate
python -m calendar_bot.main
```

Также можно использовать скрипт:

```bash
./start_bot.sh
```

## Команды бота

- `/start` — приветственное сообщение;
- `/list` — показать текущие сохранённые события;
- `/delete` — выбрать и удалить событие;
- `/cancel` — отменить текущее действие.

Основные действия также доступны через кнопки Telegram-меню. Любое обычное
текстовое сообщение бот пытается разобрать как событие, после чего показывает
черновик и ждёт подтверждения.

Пример:

```text
завтра в 15:00 встреча с преподавателем на час
```

После успешного разбора событие сохраняется в SQLite.

## SQLite

База данных хранится в файле, путь к которому задаётся переменной
`DATABASE_PATH`. По умолчанию в примере используется:

```text
calendar_bot/database.sqlite3
```
